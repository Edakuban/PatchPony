# Lokale Entwicklung

1. Kopiere `.env.example` nach `.env`.
2. Trage den destination.one-API-Endpunkt und den API-Schlüssel ausschließlich in `.env` ein.
3. Verwende für erste Tests das Modell `gpt-oss:20b`.
4. Lege ein lokales Entwicklungspasswort in `PATCHPONY__AUTH__DEVELOPMENTPASSWORD` fest.

Die Werte `PATCHPONY__AI__ENDPOINT`, `PATCHPONY__AI__APIKEY` und `PATCHPONY__AUTH__DEVELOPMENTPASSWORD` dürfen nicht geloggt werden.
