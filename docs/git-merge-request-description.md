# Merge-Request-Beschreibung

PR-Beschreibungen bestehen aus fünf festen Abschnitten: Ticket, Plan, Diff-Zusammenfassung, Tests und Risiken. Der Builder akzeptiert nur begrenzte, kontrolldatenfreie strukturierte Felder; Steuerzeichen, übergroße Listen und rohe stdout/stderr-Ausgabe werden abgewiesen.

Die Beschreibung verwendet Markdown mit fester Struktur und enthält nie Credentials, HTTP-Fehlerantworten oder frei eingebrachte Git-Parameter.
